Accessibility

Built for when it's too much.

A big event is a lot for anyone. Every control is there for everyone, not tucked away as a special mode.

Pause and catch up

Freeze the transcript without losing your place. See how many new lines came in, and jump back to live.

Calm mode

One column. Only the latest lines, larger and quieter. Chat and side panels step out of the way.

Text size and contrast

Bigger type and a high-contrast theme, on every screen.

Screen reader control

New lines are read aloud only if you ask. Otherwise the transcript stays quiet.

Keyboard first

Every room, tab and control works without a mouse.
